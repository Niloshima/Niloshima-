# MineZone Web Arcade - Full GitHub Pages Setup Guide

Welcome to your 100% Free, Static Web Arcade Site!

## 🚀 How to Host Free 24/7 on GitHub Pages:
1. Extract this `minezone-web-arcade.zip` file.
2. Go to [GitHub.com](https://github.com) and sign in.
3. Create a **New Repository** named `arcade` (or `yourusername.github.io`).
4. Upload all the files inside this folder (`index.html`, `play.html`, `css/`, `js/`, etc.) into your repository root.
5. Go to **Settings > Pages** in your GitHub repository.
6. Under **Build and deployment**, select **Source: Deploy from a branch** and pick `main` (or `master`) branch.
7. Click **Save**. Within 1-2 minutes, your website will be LIVE 24/7 at `https://yourusername.github.io/arcade`!
